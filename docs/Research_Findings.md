# Research Findings — Tabl (Android Medication Reminder)

## Executive Summary

Рынок приложений для напоминания о таблетках перегрет платными решениями и перегружен ненужными трекерами здоровья. Главная боль пользователей — стандартные push-уведомления легко проигнорировать. Единственный бесплатный Android-конкурент с настойчивыми будильниками (Pillo) слабо известен. Технически задача решается нативными Android API (AlarmManager + WorkManager) без бэкенда.

---

## Research Objective

1. Какова реальная боль пользователей при приёме таблеток?
2. Какие технические решения обеспечивают надёжные будильники на Android?
3. Чего не хватает текущим конкурентам?
4. Какой минимальный стек для нативного Android-приложения без бэкенда?

---

## Methodology

- Анализ 6 конкурирующих приложений (функции, цены, отзывы)
- Исследование Android API для фоновых задач и будильников
- Анализ жалоб пользователей в App Store / Google Play

## Market Analysis

### Размер рынка и тренды

- Глобальный рынок mHealth apps: >$111 млрд к 2025 году [H]
- Medication adherence (приверженность лечению) — ключевая проблема: ~50% пациентов с хроническими заболеваниями не соблюдают режим приёма [H]
- Основная причина пропуска доз: забывчивость (>60% случаев) — решаемо приложением
- Спрос на бесплатные решения растёт на фоне монетизации Medisafe (январь 2026)

### Ключевая инсайт из отзывов пользователей

> "Уведомления легко смахнуть, когда ты занят, а потом забываешь что уже принял или нет"

> "Medisafe теперь платный — ищу бесплатную замену"

> "Не нужны трекеры давления и сахара, просто напомни мне выпить таблетку"

|-----------|------|-----------|----------------|-----------------|---------------|

### Конкурентные слабости

- **Medisafe**: стал платным → потеря базы пользователей
- **MyTherapy**: перегружен трекерами → сложный UX для простой задачи
- **Pillo**: хороший конкурент, но малоизвестен, нет iOS
- **MedTimer**: нет настойчивых будильников
- **Mediteo**: ограниченный бесплатный тариф

### Дифференциация Tabl

```
Tabl = Надёжность Pillo + Простота MedTimer + 0 трекеров
```

## Technology Assessment

### Android Alarm Architecture

**Проблема push-уведомлений:**
- Android с версии 8.0+ агрессивно ограничивает фоновые процессы
- Push-уведомления можно смахнуть одним жестом
- Нет гарантии доставки при режиме экономии батареи (Doze mode)

**Решение: AlarmManager + полноэкранный Intent**

```kotlin
// Точный будильник (требует SCHEDULE_EXACT_ALARM permission с API 31+)
alarmManager.setExactAndAllowWhileIdle(
    AlarmManager.RTC_WAKEUP,
    triggerTime,
    pendingIntent
)

// Полноэкранный Intent (поверх локскрина)
notification.fullScreenIntent = fullScreenPendingIntent
notification.flags = FLAG_INSISTENT  // повторяет звук непрерывно
```

**WorkManager для периодических задач:**
- Управление расписанием напоминаний
- Устойчив к перезагрузке устройства
- Поддерживает ограничения (только при включённом экране и т.д.)

**Room Database:**
- Локальное хранилище лекарств и истории
- Без синхронизации с сервером
- Полная приватность

### Рекомендуемый стек

| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| Язык | Kotlin | Официальный язык Android |
| UI | Jetpack Compose | Современный декларативный UI |
| БД | Room (SQLite) | Локальное хранение, нет сервера |
| Будильники | AlarmManager | Точные будильники через системный API |
| Фон | WorkManager | Устойчивые фоновые задачи |
| DI | Hilt | Стандарт для Android |
| Навигация | Navigation Compose | Официальная библиотека |
| Min SDK | API 26 (Android 8.0) | Охват >97% устройств |

## User Insights

### Поведенческие паттерны

- Пропуск происходит чаще утром (спешка) и вечером (усталость)
- Пожилые пользователи предпочитают большие кнопки и контрастный текст
- Люди на курсовых препаратах (антибиотики) особенно склонны забывать к середине курса
- Пользователи НЕ хотят регистрацию — барьер для установки

### Критические UX-требования

1. Экран подтверждения должен открываться ПОВЕРХ локскрина
2. Звук будильника должен продолжаться до подтверждения
3. Добавление лекарства — не более 3 шагов
4. Интерфейс работает без интернета с первого запуска
