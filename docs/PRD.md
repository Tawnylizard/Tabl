# Product Requirements Document — Tabl

**Версия:** 1.0  
**Дата:** 2026-04-16  
**Платформа:** Android (API 26+)

---

## Executive Summary

Tabl — бесплатное нативное Android-приложение для напоминания о приёме лекарств. Ключевое отличие от конкурентов: **настойчивый будильник**, который не умолкает до подтверждения приёма. Нет трекеров здоровья, нет регистрации, нет интернета, нет рекламы.

---

## Problem Statement

50% пациентов с хроническими заболеваниями нарушают режим приёма лекарств. Главная причина — забывчивость. Существующие бесплатные решения используют обычные push-уведомления, которые легко проигнорировать. Платные решения (Medisafe) недоступны для части пользователей. Решения с трекерами (MyTherapy) перегружают пользователей лишними функциями.

## Feature Requirements

### F1: Управление лекарствами

**F1.1** Добавление лекарства:
- Название (текст, обязательно)
- Доза (текст, опционально: "1 таблетка", "5 мг")
- Цвет иконки (для визуального различия)
- Количество в запасе (число, опционально)
- Порог напоминания о пополнении (число, опционально)

**F1.2** Редактирование лекарства  
**F1.3** Удаление лекарства (с подтверждением)  
**F1.4** Пауза напоминаний (без удаления)

### F2: Расписание

**F2.1** Добавление времени приёма к лекарству  
**F2.2** Типы расписания:
- Конкретное время (09:00, 21:00)
- Дни недели (пн-пт, каждый день, выборочно)
- Курс: с [дата] по [дата]
- Интервал: каждые N часов

**F2.3** Несколько временных слотов для одного лекарства  
**F2.4** Гибкий период (приём с ... по ..., бессрочно)

### F3: Будильник и уведомления

**F3.1** Точный будильник через AlarmManager  
**F3.2** Срабатывание поверх локскрина (FullScreenIntent)  
**F3.3** Настойчивый звук: FLAG_INSISTENT — повторяется пока не ответишь  
**F3.4** Вибрация синхронизирована со звуком  
**F3.5** Автоматический повтор каждые 5 минут при отсутствии ответа (макс. 3 раза)  
**F3.6** После 3 повторов без ответа — статус "пропущено"  
**F3.7** Работа при выключенном экране (RTC_WAKEUP)  
**F3.8** Устойчивость к перезагрузке (BOOT_COMPLETED receiver)

### F4: Экран подтверждения приёма

**F4.1** Открывается поверх локскрина автоматически  
**F4.2** Показывает: название лекарства, дозу, время  
**F4.3** Кнопка **"Принял"** — фиксирует приём, останавливает будильник  
**F4.4** Кнопка **"Снуз"** — откладывает на 5/10/15 минут (выбор)  
**F4.5** Кнопка **"Пропустить"** — фиксирует пропуск, останавливает будильник  
**F4.6** Большие кнопки (мин. 56dp) для удобства использования полусонным  

### F5: История приёмов

**F5.1** Лог каждого события: принято / пропущено / отложено  
**F5.2** Фильтрация по лекарству и дате  
**F5.3** Визуальный календарь (месяц) с цветовой кодировкой  
**F5.4** Процент соблюдения за 7/30 дней

### F6: Напоминание о пополнении запасов

**F6.1** Автоматическое уменьшение счётчика при каждом "Принял"  
**F6.2** Уведомление (обычное) когда остаток ≤ порогу  
**F6.3** Ручное обновление количества

### F7: Настройки приложения

**F7.1** Громкость будильника (независимо от системной)  
**F7.2** Мелодия будильника (из системных + "тихий режим")  
**F7.3** Длительность снуза по умолчанию (5/10/15 мин)  
**F7.4** Максимальное количество снузов (1/2/3/без лимита)  
**F7.5** Тёмная / светлая / системная тема  
**F7.6** Язык интерфейса (русский, английский)

## Non-Functional Requirements

| NFR | Требование |
|-----|-----------|
| **Точность будильников** | Отклонение ≤ 1 минуты от запланированного времени |
| **Надёжность** | Будильник срабатывает после перезагрузки устройства |
| **Производительность** | Холодный старт ≤ 2 секунды |
| **Размер APK** | ≤ 15 МБ |
| **Автономность** | 100% offline, нет сетевых запросов |
| **Приватность** | Никакие данные не покидают устройство |
| **Доступность** | Минимальный размер шрифта 14sp, контраст WCAG AA |
| **Min Android** | API 26 (Android 8.0) |
