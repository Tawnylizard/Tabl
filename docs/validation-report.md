## Security Assessment

**Применимость:** НИЗКАЯ — приложение 100% offline, без аутентификации, без сетевых запросов, без multi-tenancy. Данные хранятся локально в SQLite через Room (параметризованные запросы по умолчанию предотвращают SQL-инъекции).

**Специфические риски для Android:**
- Intent hijacking: BroadcastReceiver для BOOT_COMPLETED и действий уведомлений должен быть `android:exported="false"` или иметь кастомное разрешение
- PendingIntent flags: использовать `FLAG_IMMUTABLE` для предотвращения перехвата intent'ов (Android 12+)
- Нет хранения чувствительных данных — названия лекарств не медицинские тайны в контексте локального хранения

**Security AC рекомендуется добавить:**
```
Given BroadcastReceiver для BOOT_COMPLETED
Then android:exported="false" И разрешение android.permission.RECEIVE_BOOT_COMPLETED
Given PendingIntent для действий уведомлений
Then флаг FLAG_IMMUTABLE установлен
```
